## 確認・公開

この版はCloudflare Pagesのサーバー側認証に対応しています。公開時のパスワードは **1003** です。認証前はHTML・画像・データ・アプリのダウンロードを含むサイト全体を表示しません。認証は12時間有効です。

1. ZIPを展開し、`_worker.js`・`_routes.json`・index.html・assets・data・downloadsを含む**一式**を、既存のCloudflare Pagesプロジェクトにアップロードしてください。`_worker.js`を省かないでください。
2. 無料プランでは、公開前にCloudflareのプロジェクト設定 → Settings → Runtime → Fail open / closed を **Fail closed** にしてください。上限到達時にも認証を迂回してファイルを表示させないための設定です。
3. シークレットウィンドウでトップページと画像URLの両方にアクセスし、パスワード入力が必要なことを確認してください。1003でログイン後、各ページを閲覧できます。

ZIPの更新だけでは公開サイトは変更されません。以前の公開デプロイは別に残るため、必要ならCloudflare上で削除してください。外部の参考サイトやLPのリンク先は、この認証の対象外です。

認証はCloudflare Pages上で動作します。HTMLをPC上で直接開いた場合は認証されず、内容の表示確認のみ可能です。一般の静的ホスティングへそのままアップロードすると保護されません。ZIP自体はサイト所有者向けの編集用データです。

パスワードの変更はCloudflareのサーバー側環境変数 `PORTFOLIO_PASSWORD`、署名鍵の変更は秘密の環境変数 `AUTH_SECRET` で指定できます。指定しない場合は同梱Workerの設定を使います。これらのサーバー設定をdata/content.jsなどのブラウザ用ファイルへ移さないでください。

参考：https://developers.cloudflare.com/pages/functions/advanced-mode/
参考：https://developers.cloudflare.com/pages/functions/routing/#fail-open--closed

## ページ構成

- index.html：プロフィール、制作実績への案内、概数による実績カード、担当業務の展開式カード
- works.html：一般公開用クリエイティブ36点のカテゴリ別一覧
- adult-works.html：アダルト要素を含むクリエイティブ87点の一覧。初期状態はぼかし付きで、選んだ画像のみ確認後に表示
- work.html：個別の制作物。URLのidで作品を指定
- pages.html：代表の記事LP、商品LP、推しMENナビのURL一覧
- adult-pages.html：その他の記事LP29件。商品別カテゴリと「過激なアダルト表現あり」の注記、外部リンク確認付き
- shipping-tool.html：送り状変換ツールの紹介・画面・ダウンロード

- data/import-manifest.json：アップロードZIPの元パスと掲載ファイルの対応表
- assets/style.css：デザイン
- assets/main.js：カテゴリ切り替え、個別表示確認、ナビゲーション、アニメーション

## 自分で作品を追加する

1. 画像や動画を assets/works/ に追加します。
2. data/content.js の works 配列に作品を追加します。
3. categoryには meta / heaven / package / personal / line のいずれかを指定します。
4. 一般公開作品は sensitive: false、ぼかし付き別ページ掲載は sensitive: true にします。

```js
{
  id: 'line-new-01',
  category: 'line',
  title: 'LINE配信用バナー',
  summary: '制作物の概要を記入します。',
  image: 'assets/works/line-new-01.png',
  mediaType: 'image',
  images: [],
  sensitive: false,
  draft: false,
  year: '2026',
  role: 'デザイン',
  tools: 'Photoshop',
  challenge: '制作の目的',
  approach: '担当したこと・工夫',
  result: '確認できた結果',
  url: '',
  originalFilename: ''
}
```

動画は .mp4 を指定すると動画プレーヤーになります。カテゴリの表示名は creativeCategories で変更できます。
ぼかしは閲覧時の表示機能であり、ファイル自体のアクセス制限ではありません。

## 今回の構成

ホームは「プロフィールの概要 → 実績 → 制作物 → 担当できること → 連絡先」の順です。詳しい経歴・実績・業務内容はクリックやキーボード操作で展開できます。業務カードは1つずつ開きます。

商品開発・EC運営カードにOEM商品開発と製薬会社との取引を追記し、業務説明は実際に行っている内容として記載しています。アプリは自主的に発案・制作したものとして紹介しています。
